# semesterkalender-site

Public web pages for the SemesterKalender app, served with GitHub Pages:

- `index.html` – landing page
- `datenschutz.html` – privacy policy (required by Google Play)

The privacy policy is generated from `docs/play-store/datenschutz.md` in the app repository;
edit it there and regenerate rather than editing the HTML by hand.

Pages settings: deploy from branch `main`, folder `/ (root)`. `.nojekyll` disables Jekyll.
